# Club Nile — Art Gallery

Drop the three gallery artworks here as:

    1.png   2.png   3.png

(Any square-ish image works; PNG or JPG. Rename this to .jpg in the catalog if
you use JPGs.) They appear on the gallery wall in the main casino room — walk up
and press A to view, tip the artist, or buy the piece.

Titles, artists, payout wallets, prices and token IDs are set per-slot in the
`GALLERY` catalog near the top of `games/clubnile.html`. Until an image is
uploaded, a placeholder frame shows in its place.
